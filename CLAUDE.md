# Путешественник (traveler)

Публичный проект: летаешь на шаттле по Солнечной системе. Расстояния и размеры настоящие
(1 единица = 1000 км), планеты стоят на сегодняшних местах (элементы орбит NASA J2000),
подробные планеты по открытым картам NASA и шейдерам. Дальше — онлайн (видно других
путешественников) и чат как бонус. Решения Томера 07.10.2026: отдельный сайт; сначала
одиночный полёт; летать без входа, писать в чат — после входа через Google.

- Адрес: https://traveler.tomerisr.org.il · репозиторий `Tomer-Isr/traveler` (публичный)
- Хостинг: GitHub Pages, деплой = `git push` в `main` (`.github/workflows/pages.yml` публикует `web/`).
  DNS: CNAME `traveler` → `tomer-isr.github.io` в Cloudflare, без прокси.
- Сервера пока нет. Онлайн и чат потребуют сервис на Railway (см. `PLAN.md`).

## Устройство
- `web/index.html` — разметка, importmap three@0.169 (jsdelivr), без сборки
- `web/main.js` — всё: сцена, плавающее начало координат (корабль всегда в 0, мир в double на JS),
  логарифмический буфер глубины, шейдеры планет (рельеф кодом: кратеры + шум через высоту и
  экранные производные, включается ближе ~2 радиусов), шаттл из примитивов, полёт, автопилот, приборы
- `web/i18n.js` — все тексты и факты (NASA Planetary Fact Sheet), ru/en
- `web/tex/` — карты: 2k (Solar System Scope, CC BY 4.0; Земля — NASA Blue Marble) и 4k,
  которые грузятся только при подлёте (`HIRES` в `main.js`)
- `window.__trav.look(id, k)` — поставить корабль в k радиусах от тела лицом к нему (для проверок)

## Правила
- Масштаб честный: не сжимать расстояния. Скорость корабля = 0.9 × высота над ближайшим телом
  (так от планеты до планеты — секунды, у поверхности — медленно).
- Каждый шейдер с `#include <logdepthbuf_*>` — строки include отдельными строками (`LDV`/`LDF`),
  иначе шейдер не собирается.
- Новый текст — ключом в оба языка `i18n.js`.
- `[hidden]{display:none!important}` в CSS обязателен: `.intro/.menu/.hud` задают `display` и перебивают атрибут.
- Проверка перед пушем: локальный сервер из `web/`, снимки Playwright (swiftshader) ПК и телефон 390px:
  заставка, у Земли, `look('saturn'|'moon'|'earth', ...)`, консоль без ошибок.
